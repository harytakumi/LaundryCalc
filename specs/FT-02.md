# FT-02 Input Berat & Notifikasi Min. Charge

Sumber PRD: Bagian 5 (BL-01), Bagian 6 (FT-02), Bagian 7 (Main User Flow), Bagian 8 (AC-01), Bagian 9 (TC-01, TC-03), Bagian 11 (store_info.minimum_charge_kg).

## Tujuan
Pengguna dapat memasukkan perkiraan berat cucian dalam kilogram serta langsung melihat pemberitahuan jika berat di bawah 3 kg dikenai batas minimal tagihan 3 kg.

## Alur
1. Saat halaman dibuka, kolom berat otomatis terisi `3` kg.
2. Pengguna dapat mengubah isi kolom dengan mengetik angka desimal (memakai koma atau titik) atau menekan tombol kurang (`-`) dan tambah (`+`) berstep `0,1` kg.
3. Jika berat valid bernilai `>= 0,1` kg dan `< 3` kg, sistem menetapkan berat ditagih menjadi `3` kg dan menampilkan pemberitahuan visual aturan minimum charge 3 kg.
4. Jika berat valid bernilai `>= 3` kg, berat ditagih sama dengan berat input pengguna dan pemberitahuan minimum charge disembunyikan.
5. Jika kolom dikosongkan, diisi `0`, atau bukan angka valid, sistem menandai berat belum valid dan memblokir pengiriman pesanan dengan pesan error di bawah kolom.

## Data
- `STORE_INFO.minimumChargeKg` di `src/config.ts`: bernilai `3.0`.
- `APP_CONFIG.defaultWeightKg` di `src/config.ts`: bernilai `3`.
- `APP_CONFIG.minWeightKg` di `src/config.ts`: bernilai `0.1`.
- `APP_CONFIG.weightStepKg` di `src/config.ts`: bernilai `0.1`.

## Aturan dan rumus
- Input berat aktual ($W_{\text{aktual}}$) menerima bilangan desimal $\ge 0,1$ kg (step `0,1` pada tombol stepper, menerima koma maupun titik pada input ketik).
- Rumus berat ditagih:
  - $W_{\text{ditagih}} = \max(3.0, W_{\text{aktual}})$
- Penanda minimum charge aktif:
  - `isMinimumChargeApplied = isWeightValid && W_aktual < 3.0`
- Aturan turunan pembulatan biaya:
  - Nilai berat input dibersihkan spasi awal/akhir; koma diubah menjadi titik saat dihitung.
  - Saat ditampilkan kembali sebagai teks (mis. label berat ditagih atau template WhatsApp), angka memakai koma tanpa nol desimal berlebih (`3`, `1,8`, `4,5`).
  - Tombol stepper `-` dan `+` mengubah nilai sebesar `0,1` kg dengan pembulatan `Math.round(val * 10) / 10` agar bebas galat floating-point, dan dibatasi minimal `0,1` kg pada tombol `-`.

## Input dan validasi
- **Kolom Estimasi Berat (`weightInput`)**:
  - Wajib diisi, `type="text"`, `inputMode="decimal"`, `name="weight"`.
  - Valid jika setelah spasi dihapus, cocok pola angka positif `>= 0,1`.
  - Jika kosong atau `0` atau negatif atau huruf:
    - Tampilkan pesan error di bawah kolom saat tombol kirim ditekan (atau saat input bernilai invalid setelah pengguna mengubahnya): `"Masukkan perkiraan berat cucian minimal 0,1 kg, contoh: 3,5."`
    - Kalkulasi total pada bar ringkasan menampilkan status belum lengkap (`-`) dan tombol kirim memblokir pengiriman lalu mengarahkan fokus ke kolom berat.

## Tampilan dan teks
- Label kolom yang selalu terlihat: `Perkiraan berat cucian (kg)`.
- Teks bantuan singkat di bawah label/input: `Minimal tagihan 3 kg untuk semua paket.`
- Tombol stepper `-` dan `+` masing-masing minimal ukuran sentuh `44 × 44 px`.
- Panel informasi minimum charge (tampil otomatis saat `0,1 <= berat < 3`):
  - Warna `bg-amber-50 text-amber-800 border border-amber-200` dengan ikon informasi (`Info`) dan teks:
    `Berat di bawah 3 kg tetap dihitung 3 kg (ketentuan minimum charge).`
- Menampilkan ringkasan kecil `Berat ditagih: [Y] kg` dengan angka `tabular-nums`.
